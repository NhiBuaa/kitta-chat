# Agent References

Optional non-normative supporting material for agents belongs here. No project-specific
reference is required merely to populate this directory.

Use [AGENTS.md](../../AGENTS.md) for authority/routing, the
[working agreement](../rules/working-agreement.md) for agent workflow, and
[docs/](../../docs/README.md) for durable project knowledge. Task progress belongs in
Issues/PRs; a reference does not grant permission or override a standard or ADR.
