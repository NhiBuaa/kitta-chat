# Agent Rules

This area owns agent-only workflow in the [working agreement](working-agreement.md).
Start with [AGENTS.md](../../AGENTS.md) for task routing and authority boundaries.

Rules that humans or software must obey are now owned by
[docs/04-standards/](../../docs/04-standards/README.md). The seven former domain-rule
filenames remain here as compatibility pointers; update their targets, not these stubs.
Required feature behavior remains in the [specification owners](../../docs/05-specs/README.md).

Developers own and approve rule changes. Keep transient task state and test results in
Issues/PRs; record significant approved decisions in the existing ADR/decision sources.
