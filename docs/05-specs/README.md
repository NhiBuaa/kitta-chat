# Specifications And Contracts

- [REST API reference](../API.md) owns the documented API surface.
- [Specification index](../../specs/README.md) routes to existing feature contracts
  and tracker-owned specifications; these retain their established paths.

Required behavior belongs in the existing spec or owning Issue, without a duplicate local
copy. Read latest Issue comments for scope/approval amendments and PRs for evidence.
Historical labels such as `done` or `active` are navigation aids, not proof of present
runtime readiness or permission to implement the feature again.
