# Retained Notes

This category is for useful non-authoritative knowledge without a stronger owner.
No project-specific note is required merely to populate it.

Existing [interview notes](../INTERVIEW_NOTES.md) remain at their established path;
verify historical claims against implementation and accepted evidence before reuse.
Promote a durable finding into its existing architecture, product, standard, spec,
decision or operational owner when appropriate. Task plans/progress and review/CI logs
belong in Issues/PRs, not here. Do not mass-move historical evidence into this folder.
