# Agent Guidance

Before meaningful work, read and follow `.agents/AGENTS.md`.
That file remains the canonical working agreement for this repository.

## Skill source

Discover skills and their exact locations from the current session's catalog, including
installed-plugin skills. Follow the skill policy and workflow routing in `.agents/AGENTS.md`;
do not restrict discovery to one directory.

## Repository guidance

### Issue tracker

Work is tracked in GitHub Issues for `NhiBuaa/kitta-chat`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles configured for GitHub Issues.
See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository using `.agents/CONTEXT.md`, `.agents/rules/`, and `docs/adr/`.
See `docs/agents/domain.md`.
